Random Meal Generator

A simple web application that uses an external meal API to randomly generate a meal and display its information, including the ingredients needed to prepare it.

-Features
Generates a random meal using an external API
Displays the meal name, image, and ingredients
Retrieves meal information through API calls
Allows users to save meals they want to keep, and reload them later
Provides a simple and user-friendly interface

-Technologies
HTML
CSS
JavaScript
REST API
API requests and JSON data

-Purpose
This project was created to practice working with APIs, retrieving and displaying external data, handling user interactions, and building a functional web application.

-What I Practiced
Making API requests
Working with JSON data
Dynamically displaying API data
Managing user interactions
Saving user-selected data
Building a responsive web interface
